This editor runs in your browser. Standalone builds currently support Windows 64-bit. Other platforms can export configurations for the Django service.

  1. Configure your server, public key and client options below.
  2. Copy the build JSON, open GitHub Actions, choose Run workflow and paste it into config_json. Leave zip_url empty.
  3. When the run completes, download windows-client from its Artifacts section.

Use a fine-grained GitHub token with Actions: read/write access to this repository. The token is sent only to api.github.com and is never saved or included in your configuration.

Workflow inputs and artifacts are accessible according to your repository permissions. Avoid putting a private permanent password in a public repository build.
